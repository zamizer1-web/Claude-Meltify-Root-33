# Art made for Root 33

| File | What | Made with |
|---|---|---|
| `title-rift.png` | The "33" tearing out of a rift for the ROOT 33 title screen (1600x900, transparent). Composited onto Root's own logo, read from the player's install at runtime. | `tools/art/make_title_rift.py` (seed 33) |

Regenerate: `python3 -I tools/art/make_title_rift.py --font <cinzel-latin-900-normal.woff2>` (the font comes from the `@fontsource/cinzel` npm package).

## Credits

- **Cinzel** typeface by The Cinzel Project Authors, used for the numerals. SIL Open Font License 1.1, see `licenses/Cinzel-OFL.txt`. The font file itself is not included in this repository.

No art from Root or Clair Obscur: Expedition 33 is stored here. Character portraits and music are read from each player's own copies of the games when the mod runs.
